SMS Verbal Consent Script

David Halat CryoMech Alerts

Before a person's mobile number is added to the CryoMech SMS alert recipient list, the following information is communicated directly to that person:

Would you like to receive automated operational text alerts from David Halat CryoMech Alerts concerning the CryoMech helium system?

Messages are sent when monitored equipment alarm conditions occur. Message frequency varies depending on system conditions. Message and data rates may apply.

You can reply STOP at any time to stop receiving messages or HELP for help. Participation is voluntary.

The person's mobile number is added to the SMS recipient list only after the person explicitly agrees to receive these messages.

Declining SMS alerts has no effect on the person's employment, laboratory access, or ability to participate in any other activity.
